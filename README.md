
# Pro Flow – Project Dev Tracker

A lightweight and fast open-source proprietary project management board built with pure HTML, CSS, and JavaScript.

Live Demo: [Project Dev Tracker Live Demo](https://samip-developer.github.io/project-dev-tracker/?utm_source=chatgpt.com)

---

## Features

- Multi-project workspace
- Kanban-style task board
- Drag and drop task movement
- Local storage data persistence
- JSON export backup system
- Keyboard shortcuts
- Editable project and column names
- Modern dark UI
- No backend required
- Fully client-side

---

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `N` | Create new task |
| `P` | Create new project |
| `E` | Export project data as JSON |
| `?` | Open shortcuts help |
| `Esc` | Close modal |
| `Enter` | Confirm action |

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome Icons

---

## Data Storage

This application stores all project data locally in your browser using `localStorage`.

No account, server, or cloud database is used.

---

## Running Locally

1. Clone the repository

```bash
git clone https://github.com/Samip-Developer/project-dev-tracker.git
````

2. Open `index.html` in your browser

No installation or build step required.
